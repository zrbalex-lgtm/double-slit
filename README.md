# Двухщелевой опыт и квантовый ластик

Домашняя презентация: reveal.js + canvas-анимации. Каждый клик кликера — шаг на экране.

## Запуск
- Онлайн: GitHub Pages (Settings → Pages → Deploy from branch → `main`, папка `/`).
- Локально: открыть `index.html` в браузере (нужен интернет для reveal.js с CDN).

## Зона выступающего
По умолчанию картинка на весь экран. При необходимости чёрную полосу сбоку можно включить в адресе:
- `?zone=22` — ширина в % экрана, справа
- `?side=left` — полоса слева

## Управление
- Кликер / стрелки / PageDown — следующий шаг
- `S` — окно заметок для выступающего
- `F` — полный экран, `B` — чёрный экран
- Звук включается после первого нажатия

## Структура
- `js/scene-title.js` — заставка (0)
- `js/scene-waves.js` — сцена 2: волны из двух щелей
- `js/scene-particles.js` — 3D-сцены: пулемёт (1), пучок электронов (3), электроны по одному (4), датчики у щелей (5), фотоны-близнецы (6), отложенный выбор (7), квантовый ластик (8)
- `js/registry.js` — регистр сцен и общие хелперы
- `js/main.js` — reveal.js, зона выступающего, связь кликов со сценами
- `js/audio.js` — звук щелчка детектора
